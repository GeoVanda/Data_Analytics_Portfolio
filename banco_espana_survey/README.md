# Data Analytics Portfolio

## Projects

### Banco de España – Financial Competencies Survey (Encuesta de Competencias Financieras)

- [Banco de España Survey](banco_espana_survey/README.md)  
  Analysis of the Financial Competencies Survey conducted by Banco de España.

This project is part of my **Data Analytics Portfolio**.  
Its purpose is to demonstrate how I structure and develop a real-world data analysis project from data preparation to visualization of results.

## Project Structure

- **data/** → datasets used 
- **scripts/** → ETL functions and data cleaning/transformation pipelines.
- **notebooks/** → exploratory data analysis (EDA) and interactive visualization notebooks.
- **visuals/** → exported charts and key analytical results.
- **README.md** → general description of the project.
